The 24-ad set

What the afternoon produces

8Anglesx 3Hooks each= 24Ads written

Every row of the ad set sheet carries a hook, the primary text, a headline, the CTA button and the brief it is shot from. The three ads of one angle share one body and differ only in the hook, so the test reads the hook. Filming, design and upload are yours.

To reach all 24

The Angle Builder needs one fact for each of the eight angles:

  1. What the product does
  2. What it is made of, or how it works
  3. A review count or rating
  4. A described alternative, and what yours does instead
  5. A price or a guarantee
  6. Your audience, in one sentence
  7. A stock level or a date
  8. A founder detail

With fewer facts you get fewer angles, three ads each, and the sheet names the fact that would add the rest.

How to install

Claude.ai or Claude Code

Download the zip and unzip it. Then pick where you run Claude.

›Download the agent team

Claude.ai, any plan with Projects

  1. Create a Project, for example "Ad team".
  2. Upload all nine SKILL.md files as Project knowledge: the eight in agents/ and the one in run-the-team/.
  3. In a chat inside the Project, ask for the job by name ("run the agent team", or "run the angle builder on this") and paste your inputs under it.

No setup: paste any SKILL.md into a new chat, paste your inputs under it, and send.

Claude Code

Agents install into ~/.claude/skills/. Run these from the unzipped the-claude-agent-media-buying-team folder:

cp -R agents/* ~/.claude/skills/
cp -R run-the-team/* ~/.claude/skills/

Always use the cp -R <dir>/* form above. Never use cp -r <dir>/*/ with a trailing slash: on macOS that copies the contents of each folder instead of the folder, so every SKILL.md lands on top of the last one in a single flat pile.

Check it worked: ls ~/.claude/skills/ | grep agent-team should list 9 folders, each with its own SKILL.md. Claude Code picks them up on the next start.

The one rule every agent follows

No invented numbers

Every agent uses only what you paste. No quote is written that a customer did not type, and no claim goes into an ad that your facts do not back. The worked examples use invented brands and made-up numbers, labelled as examples. Replace them with your own.

  • It does not connect to anything

    Meta, Google, Shopify: none of them. You paste, Claude reads.

  • It does not film, design or upload

    It writes the words and the shot lists for each ad. Making the creative is yours.

  • It does not fill gaps

    A missing input prints [NEEDS: the missing input] in place of a guess.
