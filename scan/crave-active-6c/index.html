01 / Proposed paid test

Test a set-saving ad against a softness ad for the Origin Legging

The Origin Legging page already offers a Legging plus Classic Bra set at 20% off, so an ad could lead with the single legging's feel or with the set saving. Meta and Google ad libraries show no live ads for the brand now, so which message earns more per ad dollar is an open question.

One change

Proposed new Meta ad test, not an observed live ad. Both ads send to the Origin Legging page and only the message changes. Ad A: "Second-skin softness, light smoothing at your core. Meet the Origin Legging." Ad B: "Legging + Classic Bra set: $118.40, vs $148 bought separately. Pick your colors." Run it as a Meta A/B test so the audience is split evenly, with equal budgets.

02 / Your store

Pair the Cross Bra set with the Mini Flare instead

The Cross Bra page's 20% set always pairs the bra with the Hi-Rise Legging. One customer review shown for the Mini Flare praises the black Cross Bra worn with the flare, so which pairing earns more per visitor is open, though with no ads running a split may take a while to read.

One change

On the Cross Bra page, show half of visitors the current set (Cross Bra plus Hi-Rise Legging). Show the other half the Cross Bra plus Hi-Rise Mini Flare, at the same 20% set discount.

03 / Your store

Make the Origin Short fit guide match its sizing advice

The Origin Short and Origin Legging pages give two size signals: the fit guide says true to size, while the description says shorts and leggings run slightly large and suggests sizing down one. One Short buyer wrote they perhaps needed to size down, another that they fit like a glove.

One change

On the Origin Short page, change the fit guide line from "True to size" to "Runs slightly large. For a snug fit, size down one." Show it to half of visitors once you confirm which fit advice is right, then apply the same fix on the Origin Legging page.

Full test plan & sources +

What we saw
The Origin Short and Origin Legging pages give two size signals: the fit guide says true to size, while the description says shorts and leggings run slightly large and suggests sizing down one. One Short buyer wrote they perhaps needed to size down, another that they fit like a glove.

Winner: orders kept past the 21-day return window per Origin Short page visitor, same visitors and window for both. Also compare size-related returns or exchanges by version.

04 / Your store

Make the free returns badge match the refund policy

Product pages show free 21-day returns, but the refund policy says buyers pay return shipping and must email for a return number first. It is unclear what "free" covers, so settle this before any ad leans on returns.

One change

Choose one rule and use the same words in both places. For example, change the badge to "21-day returns, email us to start", or update the policy if you cover return postage.

Compare the two store pages

What we saw
Product pages show free 21-day returns, but the refund policy says buyers pay return shipping and must email for a return number first. It is unclear what "free" covers, so settle this before any ad leans on returns.

What to measure
Track purchases per product-page visitor before and after, as background only. Also watch: return rate, return postage cost and return-related support emails.

Test setup
Choose one rule and use the same words in both places. For example, change the badge to "21-day returns, email us to start", or update the policy if you cover return postage.
