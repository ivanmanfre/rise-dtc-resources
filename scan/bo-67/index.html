01 / Paid ads

Point the vitamin C glow ad to No.17

Your 'glow serum' image ad promises hyaluronic acid and vitamin C, but its recorded destination is the UK Anti-Aging Serum Set, built on 5% Argireline, hyaluronic acid and vitamin B5. Another of your ads with the same vitamin C line links to No.17, so this click may not find the serum it promises.

One change

As an untested proposal, first confirm the current Anti-Aging Serum Set link is not intentional. Then keep the ad copy and image unchanged and run a two-version Meta A/B test in the UK with the same audience and budget. Version A keeps the Anti-Aging Serum Set page. Version B lands on your UK No.17 Glow Serum page, which describes vitamin C. This changes the destination only.

02 / Paid ads

Test carousel ad landing: homepage versus all-products page

Your 'Skin first. Tan second. Always both.' carousel sends clicks to two different pages. Your homepage explains the duo-set idea, while your all-products page opens with single tanners such as No. 2 Tan Water at €19,20 and repeats the same line. Public data does not show which page earns more per click.

One change

As an untested proposal, run the carousel as a two-version Meta A/B test with identical copy, cards, audience and budget. Version A sends every card to the homepage. Version B sends every card to the all-products page. Run both in the same euro market so prices and shipping thresholds match. First check which cards link to which page, and keep any product-specific card links unchanged in both versions.

New No.5 video: apply, let dry, get dressed

Your No.5 page already says 'apply. let dry. get on with your day.' and promises no transfer. A verified buyer, Amanda C., describes that scene, 'apply, get dressed and enjoy your day', while noting that colour builds over a few applications.

One change

As an untested proposal, film a short video of that routine: mousse applied, a brief dry, then clothes on. Draft copy: 'Apply. Let it dry. Get dressed. Colour builds over a few applications.' Run it against a new texture-led ad that sends every click to the No.5 page, with the same audience and budget.

04 / Proposed paid test

Test a SkinSAFE-led ad for Face & Body Set

Your FAQ handles the patch-test question for sensitive skin, and also states that your whole self-tanning range holds a 100/100 SkinSAFE rating. Your €54 Face & Body Self Tan Set pairs No.9 face cream with No.5 mousse, so that third-party rating could lead a set ad.

One change

As an untested proposal, create a new Meta ad for the Face & Body Self Tan Set. Draft: 'Rated 100/100 by SkinSAFE. Face and body self tan made with sensitive skin in mind.' Run it against an ingredient-led ad for the same set, with the same audience, budget and set page. Run both in one market, using that market's set price. Confirm the rating covers both No.9 and No.5 first.
