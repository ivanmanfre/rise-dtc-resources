01 / Paid ads

Add the 20% subscription saving to the creatine ad

In the ad text we read, the creatine ad names the formula but gives no price or offer. The product page shows a subscribe price of £24.00 against £30.00 one-time, so the saving is only seen after the click.

One change

Add one line to the existing Creatine Complex ad: 'Subscribe and save 20%: £24.00 for a 30-day supply.' The control keeps the current copy, including the required claim footnote. Both versions send people to the same unchanged page.

02 / Paid ads

Test mind-and-muscle against the perimenopause creatine ad

The creatine ad opens with perimenopause and muscles. The page frames the product more widely, so it is unresolved which opening angle brings more buyers to the same page.

One change

Run a second version of the ad that opens: 'Power is more than muscle. Mind and muscle support in a daily scoop.' Keep the same claim footnote, destination and audience split. Only the opening angle changes, so this is a creative message test.

03 / Paid ads

Test a small-dose answer in the collagen creator ad

The Collagen 500 Plus page asks 'Why is your dose so low compared to many others?', so dose is a question the page expects. The ad text we read does not mention dose, and the video's spoken content was not reviewed.

One change

Keep the current creator video as the control. In the variant, add an opening caption to the same video: 'One 3g scoop a day. Smaller peptides, smarter formula.' Use the same landing page, audience and dates for both versions. This is a creative message test only.
