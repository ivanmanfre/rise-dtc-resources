How to use it

You need a Claude account and the folder

There is nothing to install, nothing to connect, and no setup step that requires anyone technical. Both paths below work. The first is the shorter one.

Step 01 · Download and unzip

Get the folder, then open one agent in Claude

Start by downloading the pack and unzipping it. Inside are thirty agent folders, each holding one SKILL.md. Every step after this one reads off that unzipped folder.

›Download the full pack

Path A: claude.ai in your browser

  1. Sign in at claude.ai.
  2. Create a Project, give it the pack's name, then add one agent's SKILL.md from the unzipped folder as project knowledge. Shorter still: open a new chat and paste the whole SKILL.md file in as your first message.
  3. Paste your own input underneath it and send.

One agent per chat. The file is the whole agent, so a chat that holds one SKILL.md holds everything that agent knows.

Path B: Claude Code, if you already have it

  1. Put the pack folder inside the project folder you work in.
  2. Ask for the agent by name: run track-03-tracking-break-checker on this, then paste your input.
  3. Claude reads the SKILL.md off disk and writes the output file the agent names.

Path B is worth it if you run several agents a week. For a first look, Path A gets you the same answer.

Step 04 · When an agent refuses

A refusal is the pack working

These agents fill a slot from your input or they name what is missing. They will not put a plausible figure where you gave them none. There are two shapes of this, and both are the agent doing its job.

  • A [NEEDS:] line

    The run continues and one slot comes back empty, labelled with the exact field to supply. From the Tracking Break Checker, where an event was pasted with no date beside it:

    Payment Info Added   (no field)
[NEEDS: the last received date for this event]

    Paste that one date, run it again, and the slot fills. Everything else in the output already stood.

  • A full refusal

    The run stops before any figure prints, because the answer would be wrong in a way you could not see. Here is the refusal from the Net Revenue Corrector, quoted from its own file:

    WINDOWS DON'T MATCH, NOTHING RESTATED
Shopify window:     <date range>
Ads Manager window: <date range>

This unit only restates a return where the revenue and
the spend describe the same days. Repull one of the two
screens on the matching window and paste again.

    decide-05-net-revenue-corrector, "What it refuses"

Step 05 · The fixtures

Run the practice input before your own

Every agent ships with at least one fixture, a made-up input file sitting in its fixtures/ folder. Open the agent, paste its fixture, and read the whole output once.

You see the format, the counts, and in several cases a refusal firing on purpose, before any of your own figures are involved.

convert/convert-05-first-screen-rewriter/
  SKILL.md
  fixtures/          <- paste one of these first

A fixture run costs you the time it takes to read one output. It is the fastest way to find out whether an agent answers the question you have.

One line each, never two

The line under every name is the output that agent exists to produce. If two agents ever gave you the same line, one of them would be filler.

Only what you paste

Nothing connects to your ad account, nothing reads your store, nothing runs on a schedule. Every figure in an output traces back to a line you supplied.

Missing fields print by name

Where your input does not carry a figure the answer needs, the agent prints the name of the missing field and leaves the slot empty.

Questions

Before you open the folder

Four things worth knowing while the download finishes.

Is it really free?

Yes. The folder is yours to keep, copy and edit. There is no seat to buy, no login of ours, and nothing to renew. A Claude account is the only thing you need on your side.

Do I need to know code?

No. Every agent is plain English in one file. You open Claude, give it the file, paste what you have, and read what comes back. Nothing is run from a terminal unless you already use one.

What if an output looks wrong?

Read the population line and the sources it printed. These agents work only from what you paste, so a thin answer usually means a thin input. Add the field it named and run it again.

Does any of my data go anywhere?

Only into the Claude chat you paste it into. The files hold no keys, connect to no account, and read nothing from your store or your ad platform.
