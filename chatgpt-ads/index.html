The setup path

Seven steps, in OpenAI's order

This is the install as OpenAI's help center lists it, with the kit's skill beside the step it helps. Read OpenAI's article.

Connect the store

From install to a synced catalog

  1. In Shopify, install or open the ChatGPT Ads app. Use Chrome or Safari.
  2. Select Connect Account.
  3. Choose an existing Ads Manager account, or create one: organization, account name, website, industry, country, currency and time zone.
  4. Select or create the OpenAI Pixel for Shopify.
  5. Connect the Pixel so your store's commerce events reach Ads Manager.
  6. Wait for your product inventory to sync. OpenAI says sync time varies with catalog size.
  7. In Ads Manager, use the synced product feed to create product ads.

Run chatgpt-ads-readiness-check before step 1 and catalog-rewriter-for-chatgpt before step 6, because the feed is built from the rows you have at that moment.

Launch the first campaign

Inside the Shopify app

  1. Select Create Campaign, then enter a campaign name, budget, optimization event and targeting.
  2. Choose the ad type: all products, single product or website.
  3. Select the products, review the ad preview, then select Create and Launch campaign.

Inside Shopify, budgets move in steps of $25. Ads Manager at ads.openai.com accepts other amounts. The campaign objective, the billing model and the conversion event cannot be changed after the campaign exists, so run chatgpt-ads-click-math first. A daily budget is a seven day average: one day can bill up to twice the budget, and a Sunday to Saturday week bills no more than seven times it.

After launch

What is normal

Allow 24 hours before treating zero impressions as a fault, and expect reporting to lag delivery by up to 7 hours. The Products tab stays empty until a product campaign has delivered. If the app will not connect, OpenAI's published checks are the browser and the account you connected. After that, write to ads-support@openai.com with the Ads Manager account you are trying to connect.

How to install

You need a ChatGPT account and the folder

There is nothing to connect and no setup step that needs anyone technical. Three routes below. Route 1 is the real install and needs a Business, Enterprise or Edu seat. Route 2 works on every plan, Free included, and takes no setup at all.

Step 01 · Download and unzip

Get the folder, then open one skill in ChatGPT

Start by downloading the kit and unzipping it. Inside are five skill folders, each holding one SKILL.md and a fixtures/ folder of practice input. Every route below reads off that unzipped folder.

›Download all 5 skills

Route 1: ChatGPT Business, Enterprise or Edu

  1. Unzip the kit.
  2. In ChatGPT, open the sidebar, go to Plugins, open the Skills tab, then Create.
  3. Choose Upload from your computer and upload one skill folder. Each folder is one skill, so upload them one at a time.
  4. Type @chatgpt-ads-readiness-check in a chat, then paste your store details underneath.

OpenAI's help center says Skills are available to eligible ChatGPT Business, Enterprise, Healthcare and Edu users. ChatGPT scans every upload, and some come back marked Needs Review. You can also just ask for the job in plain words: a skill triggers on its own when your request matches its description.

Route 2: any ChatGPT plan, Free included

  1. Open the skill's folder and its SKILL.md file.
  2. Copy the whole file and paste it into a new chat.
  3. Paste your own details underneath it and send.

No setup at all. Free, Plus and Pro accounts do not carry the Skills upload, so this is the route there, and it is where to start if you only want to try one skill first. On Plus and above you can paste the file into a Project's instructions instead, so every chat in that project carries the skill.

Route 3: Codex or Claude Code

  1. Put the unzipped chatgpt-ads-launch-kit folder inside the project you work in.
  2. For Codex, run: cp -R chatgpt-ads-launch-kit/* ~/.agents/skills/
  3. For Claude Code, run: cp -R chatgpt-ads-launch-kit/* ~/.claude/skills/

One command copies all five folders into place, and both tools pick them up on the next start. Codex invokes a skill with $chatgpt-ads-readiness-check.

Worth knowing before you open it

What these will not do

Every one of these files works off the same rule. It reads what you paste, it prints what that supports, and it stops where the paste runs out.

  • No store or ad account connection

    Nothing here logs into Shopify or ChatGPT Ads Manager. There is no key to enter and no permission to grant.

  • No promise of approval

    OpenAI reviews every advertiser and every ad. The readiness check reads the published rules and says which items pass on what you pasted. Only OpenAI decides the rest.

  • No benchmark, anywhere

    OpenAI publishes none for this channel, so the kit carries none. The only conversion rate Click Math will use is one you supply, with the arithmetic shown.

  • Missing input, named

    When a skill needs a fact or a figure that was not in your paste, it prints [NEEDS:] and names the exact field. It never writes a product fact your own store does not state.
