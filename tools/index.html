How to read a tool

Three rules that hold on all 22 pages

Every page in this set is built the same way, so once you have read one you can read the other 21 at a glance.

Returns run through everything

A returned order refunds the revenue, keeps the outbound label, keeps the card fee and costs you handling on the way back. Every money tool here carries the same returns arithmetic, so the answers agree with each other.

Estimates print as a range

Where an input is something you are estimating, the tool flexes it in both directions and prints the spread. Where there is nothing to flex, the range collapses and the page tells you why.

Every stat carries its source

Published figures appear as the sentence the publisher wrote, with the period the data covers and a link. Where we could not verify a figure, the page prints no benchmark at all.
